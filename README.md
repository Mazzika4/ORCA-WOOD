# ORCA - جدول متابعة العملاء (نسخة السيرفر)

بدون أي مكتبات. المطلوب فقط **Node.js 18 أو أحدث**.

## تشغيل
```
SIGNUP_CODE=اختر-كود-سري node server.js
```
افتح `http://localhost:3000` وأنشئ أول حساب (يحتاج الكود لو حددته).

## متغيرات البيئة
- `SIGNUP_CODE`: كود التسجيل. **حدده دايماً**؛ وبدونه أول حساب فقط يُنشأ والباقي مقفول.
- `PORT`: المنفذ (الافتراضي 3000).
- `DATA_DIR`: مكان حفظ البيانات (الافتراضي مجلد `data` جنب السيرفر).
- `TRUST_PROXY=1`: لو السيرفر ورا nginx أو Cloudflare.

## البيانات (مهم)
كل حاجة في `DATA_DIR`: `db.json` (العملاء والحسابات)، مجلد `files` (ملفات أمر التصنيع)، ومجلد `backups` (نسخة يومية من db.json، آخر 30 يوم).
- لازم `DATA_DIR` يكون على **قرص دائم (Persistent Disk/Volume)**، وإلا البيانات هتضيع مع إعادة النشر.
- خُد نسخة من مجلد `DATA_DIR` كله بشكل دوري خارج السيرفر.

## النشر
- **VPS:** ارفع المجلد، شغّله بـ `pm2 start server.js --name orca` (أو systemd)، وحط nginx أو Caddy قدامه بشهادة HTTPS.
- **Render / Railway / Fly:** أمر التشغيل `node server.js`، وأضف Volume واضبط `DATA_DIR` على مساره.
- **cPanel:** لازم تدعم "Setup Node.js App"، ولو ما فيهاش Node هتحتاج VPS.
- استخدم HTTPS دايماً حتى ما تنتقلش كلمات المرور بشكل مكشوف.
